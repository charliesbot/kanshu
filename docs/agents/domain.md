# Domain Docs

This repository uses a single-context domain model.

Before exploring an area, read:

- `CONTEXT.md`, when present
- Relevant decisions under `docs/adr/`, when present
- The project documents referenced by `AGENTS.md`

Missing context or ADR files are not errors. Continue silently; create them only when domain-modeling work requires them.

Use the vocabulary defined by the project's domain documents. If proposed work conflicts with an existing decision, identify the conflict explicitly.
