# Issue tracker: GitHub

Issues and specs for this repository live in GitHub Issues. Use the `gh` CLI for all operations and infer the repository from the current Git remote.

## Conventions

- Create, inspect, update, label, comment on, and close issues with `gh issue`.
- Pull requests are not a request or triage surface.
- When a skill says to publish to the issue tracker, create a GitHub issue.
- When a skill says to fetch a ticket, retrieve its body, comments, and labels.
